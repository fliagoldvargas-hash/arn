# Neurix Docs Behaviors

## Scroll
- Top navigation becomes more opaque/blurred after scroll, matching homepage behavior.
- Documentation sections are revealed by scroll; original has very low-contrast, fade-like presentation in full-page screenshots.

## Click
- Explore Market routes toward marketplace content.
- Launch Agent routes toward build/platform content.
- Docs nav item opens `/docs` in the local clone.
- Wallet button connects to Phantom/Solflare injected providers or opens Phantom when no wallet is detected.

## Hover
- Nav links, buttons, and bordered controls brighten subtly on hover.

## Responsive
- Desktop uses two-column grids and horizontal process rows.
- Tablet/mobile stack all cards to one column and reduce padding/type sizes.
