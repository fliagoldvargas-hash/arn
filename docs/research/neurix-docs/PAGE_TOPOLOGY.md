# Neurix Docs Page Topology

Target: https://www.neurix.sh/docs

## Global Layout
- Fixed black navigation bar at the top, same as the homepage.
- Single-column editorial documentation layout, centered around a 720px content width.
- Large vertical spacing and black background with subtle column grid lines.
- Serif italic headings, uppercase micro labels, thin bordered content panels.

## Sections
1. Navigation: fixed top nav with brand, Build, Marketplace, Docs, X, and wallet connect.
2. Hero: documentation eyebrow, two-line serif hero title, description, Explore Market and Launch Agent buttons.
3. Problem/Solution: two bordered panels.
4. Process: four horizontal rows with large numeric labels.
5. Skill Market: intro paragraph and six bordered capability cards.
6. Audience: two bordered feature-list cards for Builders and Investors.
7. Vision: wide bordered panel with central statement and three supporting metrics.
8. Trust & Safety: heading, paragraph, and prevention pills.
9. Technical Documentation: wide centered bordered panel marked Coming Soon.
10. Disclaimer and footer.

## Interaction Models
- Navigation visual state changes after scroll.
- Wallet connect uses injected Solana wallets.
- Buttons and links have hover states.
- No tabs, carousels, modals, videos, or canvas were detected.
