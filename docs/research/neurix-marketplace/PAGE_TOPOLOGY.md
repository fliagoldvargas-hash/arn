# Neurix Marketplace Topology

Target: https://www.neurix.sh/marketplace

## Sections

1. Fixed navigation
- Brand left, center links, utility actions right.
- Interaction model: static with hover states; nav remains fixed.

2. Hero / collection intro
- Small overline, large italic "Agent Library" headline, short body copy.
- Four metric cells underneath.
- Interaction model: static visual section.

3. Search and controls
- Centered search field.
- Tab row left and sort select right.
- Interaction model: visual demo controls; original does not require backend behavior for this clone.

4. Agent card grid
- Three dark cards in desktop grid.
- Each card includes avatar, name, ticker, description, red sparkline, price, change, metrics and CA.
- Interaction model: hoverable card surface.

5. Footer
- Minimal centered links and copyright.

## Responsive

- Desktop: 3-card grid, 4 metric cells.
- Tablet/mobile: single-column card grid, metric cells reduce to 2 columns.
